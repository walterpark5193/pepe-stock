# pepe-stock

주가에 따라 표정이 바뀌는 페페를 Claude Code 사이드 패널에 그려 주는 모드입니다. 종목을 하나 정하면 5분봉 기준 **최근 1시간 등락률**을 5분마다 받아와, 등락 구간에 맞는 페페 얼굴과 가격·등락률·스파크라인을 보여 줍니다.

## 설치

이 폴더가 그대로 마켓플레이스입니다(`.claude-plugin/marketplace.json`). 터미널 세션의 프롬프트에서:

```
/plugin install pepe-stock --marketplace /home/ec2-user/claude-lab/pepe-stock
```

셸에서는 `claude plugin install pepe-stock --marketplace /home/ec2-user/claude-lab/pepe-stock`. GitHub에 올린 뒤에는 경로 대신 `<owner>/<repo>`를 씁니다. 설치 중에 마켓플레이스 추가 여부(`y`)와 범위를 묻습니다. 개발 중에는 `claude --plugin-dir /home/ec2-user/claude-lab/pepe-stock`으로 한 세션에만 올릴 수 있습니다.

## 사용법

```
/pepe MSFT        종목을 정하고 패널을 엽니다 (미국 티커, BTC-USD 같은 코인도 됩니다)
/pepe 005930      국내 종목은 6자리 코드만 넣으면 .KS를 붙여 찾고, 없으면 .KQ로 다시 봅니다
/pepe             기억해 둔 마지막 종목으로 패널을 다시 엽니다
/pepe off         패널을 닫고 조회를 멈춥니다
```

## 동작

- 데이터는 Yahoo Finance chart API(5분봉, 당일)에서 받습니다. 키가 필요 없습니다.
- 1시간 등락률 = 마지막 5분봉 종가 ÷ 60분 전 봉 종가. 개장 1시간 안이면 당일 첫 봉 기준으로 계산하고 "개장 후 N분"이라고 적습니다.
- 표정 구간(1시간 등락률): 환희 ≥ +2.5% · 행복 ≥ +1.0% · 뿌듯 ≥ +0.3% · 무표정 ±0.3% · 불안 > −1.0% · 슬픔 > −2.5% · 오열 그 아래. 조회 중, 오류, 종목 미설정 얼굴이 따로 있습니다.
- 장중에는 5분마다, 장 마감 중에는 30분마다 조회합니다. 마감 중에도 마지막 1시간 기준 표정을 유지하고 "장 마감 HH:MM"을 거래소 시간으로 표시합니다.
- 마지막 종목은 기억해 두고 다음 세션 시작 때 자동으로 조회해 패널을 띄웁니다.

## 알아둘 점

- Yahoo의 비공식 API라 응답 형식이 바뀌면 조회가 실패할 수 있습니다. 시세는 지연될 수 있습니다.
- 등락 색은 한국식입니다: 상승 빨강 ▲, 하락 파랑 ▼.
- 세션 시작 때 자동으로 여는 패널은 터미널이 144열 이상일 때만 그려집니다. 좁은 터미널에서는 `/pepe`를 한 번 쳐서 여세요.
- 얼굴은 `tools/make-faces.py`가 픽셀로 그려 브라유 점자 문자(U+2800–28FF)로 바꾼 그림입니다. 점자와 ASCII만 써서 한국어 로캘 터미널에서도 한 글자가 한 칸입니다. 패널이 34열·19줄보다 작으면 얼굴을 빼고 글만 보여 줍니다.
