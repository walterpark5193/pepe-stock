# pepe-stock 모드 설계 (2026-11-17)

## 의도
`/pepe MSFT`처럼 종목을 넣으면, 그 종목의 **최근 1시간 등락률(5분봉 기준)** 에 따라 표정이 바뀌는
페페 아스키 아트를 Claude Code 채팅 옆 **사이드 패널(pane)** 에 그려 주는 모드.
코딩하는 동안 곁눈질로 주가 분위기를 느끼는 재미용 위젯이다.

## 목표 / 비목표 / 실패 조건
- 목표: 종목 입력 한 번, 5분마다 자동 갱신, 등락률 구간별로 다양한 페페 표정, 가격·등락률·간이 스파크라인 표시.
- 비목표: 매수가 대비 손익, 여러 종목 동시 표시, 알림/토스트, 장전·장후 거래, 차트 분석.
- 실패 조건: 네트워크 오류나 잘못된 티커에서 패널이 멈추거나 빈 화면으로 남는 것. 항상 상태를 말하는 얼굴이 떠 있어야 한다.

## 제약
- 모드는 `$`로만 바깥에 닿는다: 네트워크 `$.http.fetch`, 타이머 `$.clock.every`, 저장 `$.store`/`$.state`.
- 패널은 `/pepe` 명령으로 열면 어느 폭에서든 자리를 잡고, 세션 시작 시 자동으로 열면 터미널 144열 이상에서만 그려진다.
- 모듈 변수는 핫 리로드 때 사라지므로, 남아야 할 값은 `$.state`(세션)·`$.store`(세션 간)에 둔다.

## 접근 방식 비교 (데이터 출처)
1. **Yahoo Finance chart v8** (`query1.finance.yahoo.com/v8/finance/chart/{티커}?interval=5m&range=1d`) — **선택**.
   키 없음, 5분봉을 바로 줌, 미국·한국(`005930.KS`)·코인(`BTC-USD`)까지 커버. 이 호스트에서 MSFT·005930.KS 응답 확인함.
   위험: 비공식 API라 언제든 바뀔 수 있음 → 받기·파싱을 `quote.ts` 한 파일에 격리해 교체 비용을 줄인다.
2. 키 필요한 공식 API(Twelve Data, Finnhub 등) — 약관상 안전하지만 가입·키 입력이 필요하고 무료 한도가 빡빡함. 보류.
3. 네이버 금융(국내 전용) — 사용자가 예로 든 미국 티커를 못 다룸. 제외.
- Stooq는 이 호스트에서 404/JS 검증 벽에 막혀 제외.

## 결정된 동작
- 명령: `/pepe MSFT` 종목 설정+즉시 조회+패널 열기 / `/pepe` 기억된 종목으로 다시 열기(없으면 사용법) / `/pepe off` 패널 닫고 조회 중단.
- 티커 정규화: 대문자화. 6자리 숫자면 `.KS`를 붙이고 404면 `.KQ`로 재시도.
- 1시간 등락률: 마지막 5분봉 종가 vs 그보다 60분 이상 앞선 가장 가까운 봉의 종가. 장 시작 1시간 안이면 당일 첫 봉 기준으로 계산하고 "개장 후 N분"이라고 적는다. `null` 봉은 건너뜀.
- 갱신: `session.start`에서 5분 타이머 하나를 돌리고, 종목이 있을 때만 조회. 장 마감 중에는 30분에 한 번만 조회.
- 장 상태: Yahoo `currentTradingPeriod.regular` 안에 현재 시각이 있으면 장중, 아니면 "장 마감 HH:MM(거래소 시간)" 표기. 마감 중에도 표정은 마지막 1시간 기준으로 유지.
- 기억: 마지막 종목을 `$.store`에 저장. 다음 세션 시작 때 자동 조회·패널 열기(좁은 터미널에선 `/pepe`로 열 때까지 대기).
- 표정 구간(1시간 등락률 %, 상수로 조정 가능):
  | 표정 | 구간 |
  |---|---|
  | 환희(선글라스·로켓) | ≥ +2.5 |
  | 행복(feels good man) | +1.0 ~ +2.5 |
  | 뿌듯(smug) | +0.3 ~ +1.0 |
  | 무표정 | −0.3 ~ +0.3 |
  | 불안(식은땀) | −1.0 ~ −0.3 |
  | 슬픔 | −2.5 ~ −1.0 |
  | 오열(눈물 줄줄) | ≤ −2.5 |
  | 생각 중 | 조회 중 |
  | 어리둥절 | 오류·없는 티커 |
  | 손 흔들기 | 종목 미설정 |
- 색: 페페 얼굴 초록, 등락 색은 한국식(상승 빨강 ▲, 하락 파랑 ▼). 등락 아래 12~13개 종가 스파크라인(▁▂▃▄▅▆▇█).
- 패널 본문(약 40열): 얼굴 9~10줄 → 종목명 → 가격·등락률 → 스파크라인 → 표정 이름·장 상태 → 갱신 시각(KST). 세로 공간이 모자라면 스파크라인·갱신 시각부터 생략.

## 파일 구성 (`~/.claude/dev-mods/<세션>/pepe-stock/`)
- `.claude-plugin/plugin.json` — 이름·버전·설명, `types` 경로.
- `hooks/hooks.json` — `register.tsx` 등록.
- `hooks/register.tsx` — 명령·타이머·패널 그리기(`$` 사용).
- `hooks/quote.ts` — Yahoo 응답 파싱, 1시간 등락 계산, 티커 정규화, 장 상태 판정. 순수 함수.
- `hooks/faces.ts` — 표정별 아스키 아트와 구간 판정. 순수 데이터.
- `hooks/pepe.test.tsx` — 파싱·계산·구간 경계 테스트, 패널 마운트 테스트(mock fetch).
- `types/index.d.ts` — `$.state` 계약.

## 빌더에게 맡기는 것
- 아스키 아트의 실제 모양과 색 배치(패널 폭 ≤ 28열, 높이 ≤ 10줄 안에서).
- Yahoo 요청 실패 시 재시도 간격(다음 타이머까지 기다리는 것으로 충분).
